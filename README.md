# Geolib apps — downloads

Desktop builds of three astronomy and calendar apps:

| App | What it is | Web version |
|---|---|---|
| **Solar System Models** (နေအဖွဲ့အစည်း မော်ဒယ်များ) | Babylonian, Ptolemaic, Copernican, Kepler, Sūrya Siddhānta and other models of the planets | <https://my-solarsystem.web.app/> |
| **Myanmar Calendar** (မြန်မာပြက္ခဒိန်) | Myanmar, Chinese, Hindu and Thai calendars and astrology | <https://myanmar-calendar-app.web.app/> |
| **Dviphala** (၂ ဖန်စင်) | Nīlakaṇṭha's two-step and the Sūrya Siddhānta four-step planetary corrections | <https://dviphala-model.web.app/> |

## Download

Get the latest version from **[Releases](https://github.com/BlacMeW/geolib-releases/releases/latest)**.

| Platform | Install | Portable |
|---|---|---|
| macOS (Apple silicon + Intel) | `*-macos.dmg`: open it and drag the app onto **Applications** | `*-macos.zip` |
| Windows x64 | `*-windows-x64-setup.exe`: run the installer (no admin rights needed) | `*-windows-x64.zip`: unzip the folder, run the `.exe` |
| Linux x64 | `*-linux-x86_64.AppImage`: `chmod +x` it and run it | `*-linux-x64.tar.gz`: extract, run `bundle/<app>` (needs GTK 3) |

The apps are not code-signed yet, so the first launch asks for confirmation:
on macOS right-click the app → **Open**; on Windows choose **More info → Run anyway** in SmartScreen.

This repository only hosts the release files; the source code is kept elsewhere.
